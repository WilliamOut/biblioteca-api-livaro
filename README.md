# LivaroAPI

Um sistema de API RESTful para gerenciamento de biblioteca, permitindo o controle de usuários, autores, livros e o fluxo de empréstimos/devoluções. Esta API foi desenvolvida em **Spring Boot** com foco em estabilidade, validação rigorosa e segurança de formato de dados.

---

## 🚀 Começando

Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.


---

## 📋 Pré-requisitos

Para instalar e executar a **LivaroAPI**, você precisará dos seguintes softwares instalados na sua máquina:
* **Instalar o Sqlite para poder visualizar os dados no banco**
* **Java Development Kit (JDK) 21:** Essencial para executar o Spring Boot.
* **Maven** (ou Gradle): Gerenciador de Dependências do projeto.
* **Git:** Para clonar o repositório.
* **Postman/cURL:** Para testar os endpoints REST.

## ⚙️ Rode a aplicação

Quando estiver no ar, acesso a documentação da api com: http://localhost:8080/swagger-ui/index.html

## 🛠️ Construído com

* **Spring Boot**: O framework principal.

* **Spring Data JPA / Hibernate**: Usado para persistência e modelagem ORM.

* **SQLite**: O banco de dados relacional usado (baseado em arquivo).

* **Springdoc OpenAPI**: Usado para gerar a documentação interativa (Swagger UI).

* **Maven**: Gerenciador de Dependência e Automação.
